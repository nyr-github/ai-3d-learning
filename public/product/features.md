## 首页项目浏览
--------------------------------------------------------------------------------

### 功能1: 浏览可用学习项目
- **位置**: 用户访问网站首页时看到的内容
- **描述**: 展示所有可用的3D学习项目（如生物学项目），每个项目显示图标、名称和描述
- **使用场景**: 用户首次访问网站，想了解有哪些3D学习内容可用
- **操作步骤**:
  1. 用户在浏览器中访问 https://show3d.aivaded.com/
  2. 页面显示项目卡片网格，每个卡片包含项目图标、标题和简短描述
  3. 用户浏览项目列表，了解当前可用的学习内容
- **界面反馈**: 项目卡片以网格布局展示，鼠标悬停时有视觉高亮效果
- **完成结果**: 用户了解平台提供的学习项目类型和范围
- **注意事项**: 当前主要提供生物学项目，未来会添加化学、物理等更多学科

### 功能2: 进入特定项目学习
- **位置**: 首页项目卡片上的点击进入按钮
- **描述**: 用户选择感兴趣的项目，进入该项目的3D学习界面
- **使用场景**: 用户决定开始学习某个特定学科（如生物学）
- **操作步骤**:
  1. 用户在首页找到感兴趣的项目卡片（如"Biology"）
  2. 点击项目卡片或"Explore"按钮
  3. 页面跳转到该项目的学习界面，显示3D查看器、侧边栏和信息面板
- **界面反馈**: 页面加载后显示完整的三栏学习界面，左侧模型列表，中间3D查看器，右侧信息面板
- **完成结果**: 用户进入特定项目的学习环境，可以开始探索3D模型
- **注意事项**: 首次加载可能需要几秒下载3D模型文件

## 3D模型查看器
--------------------------------------------------------------------------------

### 功能3: 360度旋转查看模型
- **位置**: 页面中央的3D查看器区域
- **描述**: 用户可以通过鼠标拖拽或触摸滑动，从各个角度旋转查看3D生物模型
- **使用场景**: 用户想从不同角度观察细胞结构、分子排列或病毒形态
- **操作步骤**:
  1. 用户在3D查看器中按住鼠标左键（或手指触摸屏幕）
  2. 向任意方向拖动鼠标（或手指滑动）
  3. 模型跟随鼠标/手指移动方向实时旋转
  4. 松开鼠标/手指，模型停留在当前角度
- **界面反馈**: 模型实时平滑旋转，可以从前后左右上下任意角度观察
- **完成结果**: 用户全面了解模型的三维结构和空间关系
- **注意事项**: 旋转操作流畅无延迟，支持连续旋转

### 功能4: 缩放查看细节
- **位置**: 3D查看器区域，通过鼠标滚轮或双指捏合操作
- **描述**: 用户可以放大查看模型的微观细节，或缩小查看整体结构
- **使用场景**: 用户想仔细观察细胞器结构、分子键合或病毒表面特征
- **操作步骤**:
  1. 用户将鼠标指针放在3D查看器上
  2. 向上滚动鼠标滚轮（或在触摸屏上用两指向外捏合）放大模型
  3. 向下滚动鼠标滚轮（或两指向内捏合）缩小模型
  4. 重复操作直到达到理想的观察尺度
- **界面反馈**: 模型平滑放大或缩小，可以看到更多细节或更广范围
- **完成结果**: 用户能够在微观细节和宏观结构之间自由切换观察
- **注意事项**: 缩放有最小和最大限制，避免过度放大看到模型内部或过度缩小看不到模型

### 功能5: 平移查看模型不同区域
- **位置**: 3D查看器区域，通过鼠标右键或中键拖拽
- **描述**: 用户可以平移模型视图，查看模型的不同部位而不改变旋转角度
- **使用场景**: 用户想查看大型模型的特定区域，如细胞的一侧或分子的某部分
- **操作步骤**:
  1. 用户在3D查看器上按住鼠标右键（或中键）
  2. 向任意方向拖动鼠标
  3. 模型视图跟随移动，显示不同区域
  4. 松开鼠标停止平移
- **界面反馈**: 视图平滑移动，可以看到模型之前不在视野中的部分
- **完成结果**: 用户能够仔细查看模型的各个局部区域
- **注意事项**: 平移不改变模型的旋转角度和缩放级别

### 功能6: 切换不同3D模型
- **位置**: 3D查看器自动响应左侧边栏的模型选择
- **描述**: 用户在侧边栏选择不同模型时，查看器自动加载并显示新的3D模型
- **使用场景**: 用户完成一个模型的学习，想查看下一个模型（如从植物细胞切换到动物细胞）
- **操作步骤**:
  1. 用户在左侧边栏浏览模型列表
  2. 点击感兴趣的模型名称或缩略图
  3. 3D查看器显示加载进度条
  4. 加载完成后，新模型出现在查看器中央
- **界面反馈**: 加载过程中显示进度指示器，加载完成后新模型自动居中显示
- **完成结果**: 用户开始查看和学习新的3D模型
- **注意事项**: 首次加载新模型需要下载时间，已查看过的模型会缓存，切换时瞬间显示

### 功能7: 重置模型视角
- **位置**: 3D查看器右侧或底部的控制按钮区域
- **描述**: 用户可以将模型重置到初始位置和角度，重新开始观察
- **使用场景**: 用户旋转、缩放、平移后迷失方向，想回到初始的标准视角
- **操作步骤**:
  1. 用户找到查看器控制区域的"Reset"或"重置"按钮
  2. 点击该按钮
  3. 模型自动回到预设的初始旋转角度和缩放级别
- **界面反馈**: 模型平滑动画回到初始位置，视角重置为标准观察角度
- **完成结果**: 用户回到模型的默认展示视角，可以重新开始探索
- **注意事项**: 重置不会清除模型，只是恢复视角设置

### 功能8: 全屏查看模型
- **位置**: 3D查看器控制区域的全屏按钮
- **描述**: 用户可以将3D查看器切换到全屏模式，获得更大的观察空间
- **使用场景**: 用户想更清楚地查看模型细节，或在课堂上投影展示
- **操作步骤**:
  1. 用户点击查看器控制区域的全屏图标按钮
  2. 浏览器进入全屏模式，3D查看器占满整个屏幕
  3. 用户在全屏模式下继续旋转、缩放、平移模型
  4. 点击全屏按钮或按ESC键退出全屏
- **界面反馈**: 查看器平滑过渡到全屏，侧边栏和信息面板隐藏，只显示3D模型
- **完成结果**: 用户获得最大化查看空间，更专注于模型观察
- **注意事项**: 全屏模式下无法访问侧边栏和信息面板，需退出全屏才能切换模型或查看信息

## 模型信息面板
--------------------------------------------------------------------------------

### 功能9: 查看模型基本描述
- **位置**: 页面右侧信息面板的顶部区域
- **描述**: 显示当前3D模型的名称、副标题和详细生物学描述
- **使用场景**: 用户想了解当前查看的模型是什么，有什么生物学意义
- **操作步骤**:
  1. 用户在3D查看器中查看某个模型（如植物细胞）
  2. 查看右侧信息面板
  3. 阅读模型名称（如"Plant Cell"）、副标题（如"Eukaryotic Cell · Autotrophic Organism"）
  4. 阅读详细描述段落，了解该模型的生物学功能和特征
- **界面反馈**: 信息面板显示模型名称、分类标签和详细描述文本
- **完成结果**: 用户了解模型的基本生物学信息和教育价值
- **注意事项**: 描述内容基于生物学教材编写，适合学生学习

### 功能10: 查看大小区间可视化
- **位置**: 信息面板的属性区域，带有滑动条的显示
- **描述**: 通过交互式滑动条展示生物结构的实际尺寸范围，帮助用户理解尺度概念
- **使用场景**: 用户想了解细胞、细胞器或分子的实际大小，建立尺度概念
- **操作步骤**:
  1. 用户在信息面板中找到"Size Range"属性
  2. 查看滑动条显示的最小值和最大值（如10-100 μm）
  3. 拖动滑动条上的指示器，查看不同尺度的可视化反馈
  4. 阅读单位标识（μm表示微米）
- **界面反馈**: 滑动条实时显示当前值，颜色高亮显示范围区间
- **完成结果**: 用户直观理解生物结构的尺寸范围和相对大小
- **注意事项**: 不同结构的尺寸差异很大，细胞用微米，分子用纳米

### 功能11: 查看显微镜可见性信息
- **位置**: 信息面板属性区域的显微镜图标标识处
- **描述**: 显示该生物结构在光学显微镜和电子显微镜下是否可见，以及观察注意事项
- **使用场景**: 用户在实验课前准备，想了解在显微镜下能观察到什么
- **操作步骤**:
  1. 用户在信息面板中找到"Microscope Visibility"属性
  2. 查看"Light Microscope"（光学显微镜）和"Electron Microscope"（电子显微镜）的可见性标识
  3. 阅读"LM Note"和"EM Note"了解具体观察要点
  4. 根据信息准备实验课的观察重点
- **界面反馈**: 可见性用图标和文字标识（如"Visible"），注释用较小字体显示
- **完成结果**: 用户了解在实验室中能用哪种显微镜观察到该结构，以及观察要点
- **注意事项**: 有些结构需要染色才能在光学显微镜下清晰观察

### 功能12: 查看关键结构特征
- **位置**: 信息面板的"Key Structures"属性区域
- **描述**: 列出该生物结构的重要组成部分，标注考试高频考点，帮助学习重点
- **使用场景**: 用户准备考试，想了解哪些结构特征是重点，需要记忆
- **操作步骤**:
  1. 用户在信息面板中找到"Key Structures"属性
  2. 查看列出的关键结构名称（如细胞壁、叶绿体、大液泡）
  3. 阅读每个结构的详细描述和功能说明
  4. 注意标注为考试高频考点的特征
- **界面反馈**: 关键结构以列表或字典形式展示，重要特征有特殊标记
- **完成结果**: 用户掌握该模型的核心结构特征和考试重点
- **注意事项**: 不同模型的关键结构数量不同，重点结构会特别标注

### 功能13: 查看趣味知识和教学要点
- **位置**: 信息面板的独立区域，通常在描述下方
- **描述**: 展示有趣的生物学事实和教学重点，激发学习兴趣和指导学习方向
- **使用场景**: 用户想深入了解模型的趣味信息，或教师想了解教学对比要点
- **操作步骤**:
  1. 用户在信息面板中向下滚动查看
  2. 阅读"Fun Fact"（趣味知识）了解有趣的生物学事实
  3. 阅读"Teaching Focus"（教学要点）了解学习重点和对比建议
- **界面反馈**: 趣味知识用特殊样式（如引用块）展示，教学要点用段落文本显示
- **完成结果**: 用户获得激发好奇心的趣味信息，了解学习的重点方向
- **注意事项**: 趣味知识帮助记忆，教学要点指导深度学习

## 侧边栏模型选择
--------------------------------------------------------------------------------

### 功能14: 按分类浏览模型
- **位置**: 页面左侧的侧边栏区域
- **描述**: 侧边栏按主分类和子分类组织所有可用的3D模型，方便用户浏览和查找
- **使用场景**: 用户想系统学习某一类模型（如所有细胞类型），或查找特定模型
- **操作步骤**:
  1. 用户查看左侧边栏
  2. 看到模型按分类组织（如"Cells"主分类下的"Basic Cell Types"子分类）
  3. 展开或折叠分类查看该类别下的所有模型
  4. 浏览模型列表，找到感兴趣的模型
- **界面反馈**: 分类以树形结构显示，当前选中的模型高亮标识
- **完成结果**: 用户了解平台提供的模型分类体系，找到目标模型
- **注意事项**: 分类帮助用户系统学习，建议按分类顺序浏览

### 功能15: 查看模型缩略图预览
- **位置**: 侧边栏模型列表项中，每个模型旁边的小图
- **描述**: 每个模型显示缩略图预览，帮助用户在点击前了解模型外观
- **使用场景**: 用户想快速浏览模型外观，选择感兴趣的模型查看
- **操作步骤**:
  1. 用户在侧边栏浏览模型列表
  2. 查看每个模型名称旁边的缩略图
  3. 通过缩略图了解模型的大致外观和颜色特征
  4. 点击感兴趣的模型加载查看
- **界面反馈**: 缩略图显示模型的典型视角，鼠标悬停时有高亮效果
- **完成结果**: 用户通过视觉预览快速选择模型，提高查找效率
- **注意事项**: 缩略图是静态图片，完整3D模型可以在查看器中旋转观察

### 功能16: 搜索特定模型
- **位置**: 侧边栏顶部的搜索框
- **描述**: 用户可以通过输入关键词搜索模型名称，快速定位目标模型
- **使用场景**: 用户知道想查看的模型名称（如"DNA"），想快速找到它
- **操作步骤**:
  1. 用户点击侧边栏顶部的搜索框
  2. 输入模型名称关键词（如"DNA"、"cell"、"virus"）
  3. 侧边栏实时过滤显示匹配的模型
  4. 点击搜索结果中的模型加载查看
- **界面反馈**: 搜索结果实时显示，不匹配的模型隐藏
- **完成结果**: 用户快速定位到目标模型，节省浏览时间
- **注意事项**: 搜索支持部分匹配，输入关键词即可

### 功能17: 查看模型加载进度
- **位置**: 侧边栏模型列表项中，加载中的模型旁边
- **描述**: 显示模型下载的进度百分比，让用户了解加载状态
- **使用场景**: 用户点击新模型后，想了解还需要等待多久
- **操作步骤**:
  1. 用户在侧边栏点击一个未加载过的模型
  2. 模型项显示加载进度条和百分比（如"Downloading... 45%"）
  3. 用户等待加载完成
  4. 加载完成后进度条消失，模型变为可选中状态
- **界面反馈**: 进度条实时更新，百分比数字递增，完成后显示完成状态
- **完成结果**: 用户了解加载进度，合理管理等待时间
- **注意事项**: 首次加载需要下载，已缓存的模型瞬间加载无进度条

## 移动端交互控制
--------------------------------------------------------------------------------

### 功能18: 触摸旋转模型
- **位置**: 移动端全屏3D查看器区域
- **描述**: 用户在手机上通过单指拖动旋转3D模型，适配触摸操作
- **使用场景**: 用户在手机上学习，想从不同角度查看模型
- **操作步骤**:
  1. 用户在手机上打开3D查看器
  2. 用一根手指按住屏幕上的模型
  3. 手指在屏幕上拖动
  4. 模型跟随手指移动方向旋转
- **界面反馈**: 模型实时跟随手指旋转，触摸响应灵敏
- **完成结果**: 用户在移动设备上获得与桌面端相同的旋转查看体验
- **注意事项**: 使用单指拖动旋转，不要用两指（两指用于缩放）

### 功能19: 触摸缩放模型
- **位置**: 移动端3D查看器区域
- **描述**: 用户通过双指捏合手势放大或缩小3D模型
- **使用场景**: 用户在手机上想查看模型细节或整体结构
- **操作步骤**:
  1. 用户在3D查看器上放置两根手指
  2. 两指向外张开（捏合打开）放大模型
  3. 两指向内捏合缩小模型
  4. 重复操作直到达到理想大小
- **界面反馈**: 模型平滑缩放，响应双指手势
- **完成结果**: 用户在移动设备上能够仔细查看模型细节
- **注意事项**: 使用两指操作缩放，单指用于旋转

### 功能20: 滑出式侧边栏菜单
- **位置**: 移动端屏幕左侧边缘，通过点击菜单按钮或从边缘滑动触发
- **描述**: 移动端将侧边栏设计为可滑出的抽屉式菜单，节省屏幕空间
- **使用场景**: 用户在手机上想切换模型，但侧边栏默认隐藏
- **操作步骤**:
  1. 用户点击屏幕左上角的菜单按钮（三条横线图标）
  2. 或从屏幕左边缘向右滑动
  3. 侧边栏从左侧滑出，覆盖部分3D查看器
  4. 用户在侧边栏中选择模型
  5. 点击模型后侧边栏自动关闭，或点击外部区域关闭
- **界面反馈**: 侧边栏平滑滑出，带有半透明遮罩层
- **完成结果**: 用户在移动端能够访问模型列表并切换模型
- **注意事项**: 侧边栏打开时会遮挡部分3D查看器，选择模型后自动关闭

### 功能21: 滑出式信息面板
- **位置**: 移动端屏幕右侧边缘，通过点击信息按钮触发
- **描述**: 移动端将信息面板设计为可滑出的抽屉，用户可以查看模型详细信息
- **使用场景**: 用户在手机上想查看模型的描述、属性、趣味知识等信息
- **操作步骤**:
  1. 用户点击屏幕右上角的信息按钮（"i"图标）
  2. 信息面板从右侧滑出
  3. 用户在信息面板中滚动查看描述、属性、关键结构等内容
  4. 点击外部区域或关闭按钮关闭信息面板
- **界面反馈**: 信息面板平滑滑出，内容可滚动查看
- **完成结果**: 用户在移动端能够访问完整的模型学习信息
- **注意事项**: 信息面板打开时无法操作3D模型，需关闭后继续查看

## 模型探索与学习
--------------------------------------------------------------------------------

### 功能22: 对比不同模型
- **位置**: 通过侧边栏切换模型，在3D查看器中先后查看
- **描述**: 用户可以依次查看不同模型（如植物细胞和动物细胞），对比它们的结构差异
- **使用场景**: 用户想理解不同细胞类型的区别，或比较不同生物结构的特征
- **操作步骤**:
  1. 用户在侧边栏选择第一个模型（如"Plant Cell"）
  2. 在3D查看器中观察该模型的结构特征
  3. 阅读信息面板中的描述和关键结构
  4. 在侧边栏切换到对比模型（如"Animal Cell"）
  5. 观察新模型，注意与前一模型的差异
  6. 对比两个模型的信息面板内容
- **界面反馈**: 切换模型时3D查看器更新，信息面板显示新模型的信息
- **完成结果**: 用户理解不同模型之间的结构差异和生物学意义
- **注意事项**: 建议对比阅读教学要点（Teaching Focus），通常会指出对比重点

### 功能23: 系统学习分类内容
- **位置**: 侧边栏按分类组织的模型列表
- **描述**: 用户可以按照分类体系（如细胞→细胞器→分子）系统学习相关模型
- **使用场景**: 用户想系统学习某一生物学主题，而不是随机查看模型
- **操作步骤**:
  1. 用户在侧边栏查看分类结构
  2. 选择一个主分类（如"Cells"）
  3. 按顺序查看该分类下的所有模型
  4. 对每个模型执行查看、旋转、阅读信息的完整学习流程
  5. 完成一个分类后，进入下一个分类继续学习
- **界面反馈**: 侧边栏分类清晰，当前学习位置有标识
- **完成结果**: 用户系统掌握某一生物学主题的全部3D模型内容
- **注意事项**: 建议按分类顺序学习，建立完整的知识体系

### 功能24: 准备实验课学习
- **位置**: 信息面板的显微镜可见性属性和关键结构区域
- **描述**: 用户通过查看显微镜可见性信息和关键结构，为实际实验室课程做准备
- **使用场景**: 用户即将进行显微镜实验课，想提前了解能观察到什么
- **操作步骤**:
  1. 用户在侧边栏选择实验课相关的模型
  2. 在信息面板中查看"Microscope Visibility"属性
  3. 阅读"LM Note"了解光学显微镜下的观察要点
  4. 阅读"EM Note"了解电子显微镜下的观察要点
  5. 查看"Key Structures"了解需要重点观察的结构
  6. 在3D查看器中旋转模型，熟悉结构的空间关系
- **界面反馈**: 显微镜可见性用图标和文字清晰标识，注释提供实用指导
- **完成结果**: 用户对实验课中将要观察的内容有清晰预期，提高实验课效率
- **注意事项**: 3D模型是理想化展示，实际显微镜下可能看到不同清晰度的结构

### 功能25: 自主探索学习
- **位置**: 整个平台的自由浏览
- **描述**: 用户可以不受限制地自由浏览所有模型，按照自己的兴趣和节奏学习
- **使用场景**: 用户对生物学感兴趣，想自主探索了解细胞和分子结构
- **操作步骤**:
  1. 用户访问网站首页
  2. 选择感兴趣的项目（如Biology）
  3. 在侧边栏浏览模型列表，被哪个模型吸引就点击哪个
  4. 在3D查看器中自由旋转、缩放、平移查看
  5. 阅读信息面板中的描述、趣味知识、关键结构
  6. 切换到下一个感兴趣的模型继续探索
- **界面反馈**: 平台提供流畅的浏览体验，模型切换快速，信息展示清晰
- **完成结果**: 用户通过自主探索获得生物学知识，培养科学兴趣
- **注意事项**: 无需按特定顺序学习，跟随好奇心探索即可
