# 从AI生成到在线展示：一套完整的3D模型展示方案

## 引言

最近你有没有注意到，网上冒出了很多用AI生成3D模型的项目？

正是看到了这个痛点，我决定做一件不一样的事情。

## 为什么我创建了这个工具

我不是一个人在战斗。这次，我选择了一套完整的中国AI工具链，从模型生成到网站开发，全流程使用国产工具：

**第一步：用豆包生成图像**
豆包的图像生成能力已经非常强大。我输入详细的提示词，生成了精美的植物细胞、动物细胞、线粒体等科学插图。

**第二步：用混元3D转成3D模型**
腾讯的混元3D可以将单张图像转换为3D GLB模型。虽然还需要一些后处理，但大大降低了3D建模的门槛。

**第三步：用Qoder开发网站**
这是最关键的一步。Qoder作为一个AI编程助手，帮助我快速搭建了整个3D展示网站。从架构设计到代码实现，从性能优化到响应式布局，整个过程高效而流畅。

我想要证明：借助中国的AI工具，任何人都可以把创意变成可分享的在线体验。

## 它是如何工作的

### 完整的AI工作流

整个流程非常简单：

1. **准备图像**：用豆包或其他AI工具生成高质量的图片
2. **生成3D模型**：使用混元3D将图片转换为GLB格式
3. **优化模型**：使用内置脚本压缩模型体积（减少50-80%）
4. **添加到网站**：只需配置JSON文件，无需写代码
5. **部署上线**：一键推送到GitHub Pages，全球可访问

### 交互式3D展示

打开网站，你会看到一个完全交互式的3D场景：

- **自由旋转**：鼠标拖拽或手指滑动，360度观察模型
- **缩放查看**：从整体到细节，放大看看内部结构
- **平移移动**：将感兴趣的部位移到视野中心

这不是简单的图片轮播，而是真正的3D体验。

### 丰富的元数据支持

每个模型不只是"好看"，还可以附带：

- **详细描述**：背景故事、科学解释
- **趣味知识**：吸引用户的有趣事实
- **教学重点**：针对教育场景的知识点
- **属性标注**：尺寸范围、显微镜可见性、位置信息等
- **考试重点**：高频考点特别标注

这些元数据通过简单的JSON配置就能添加，不需要修改代码。

### 开箱即用的架构

项目采用Next.js + Three.js + React Three Fiber技术栈：

- **静态网站**：零服务器成本，部署到GitHub Pages即可
- **智能缓存**：模型加载后保存在内存中，切换无需等待
- **DRACO压缩**：支持高度压缩的GLB格式，加载速度提升数倍
- **响应式设计**：桌面端和移动端完美适配

最重要的是，代码完全开源，你可以：

- 直接使用，展示你自己的3D模型
- 修改配置，定制成你的品牌风格
- 扩展功能，添加你需要的特性
- 学习参考，理解3D Web开发的最佳实践

### 智能模型加载系统

不是简单地"下载-显示"，而是采用了高级策略：

1. **内存缓存**：已加载的模型保存在内存，切换秒开
2. **预加载机制**：预测用户可能查看的下一个模型，提前加载
3. **状态驱动**：清晰跟踪每个阶段（空闲 → 下载 → 解析 → 完成）
4. **错误处理**：优雅处理网络问题和格式错误

### 性能优化

- **自适应DPR**：支持视网膜显示器，平衡清晰度和性能
- **WebP图片**：预览图使用WebP，比PNG/JPG小30-50%
- **DRACO压缩**：模型文件减少50-80%
- **环境贴图**：HDR工作室灯光，呈现逼真材质

## 开始使用

### 快速部署

```bash
# 克隆仓库
git clone <仓库地址>
cd ai-3d-learning

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

访问 `http://localhost:3000` 即可看到效果。

### 添加你自己的模型

1. **准备GLB文件**，放在 `public/models/` 目录
2. **准备预览图**（WebP格式），放在 `public/images/` 目录
3. **添加配置**，在 `data/projects/` 下创建或修改数据文件：

```typescript
{
  id: "my-model",
  name: "我的模型",
  description: "模型描述...",
  model3D: {
    modelUrl: "/models/my-model.glb",
    imageUrl: "/images/my-model.webp",
    displayScale: 1.0,
  }
}
```

4. **运行**，立即看到效果！

### 优化你的模型

```bash
# 压缩GLB文件（减少50-80%体积）
pnpm optimize:glb ./public/models

# 转换图片为WebP
pnpm convert:webp ./public/images

# 同步文件大小到配置文件
pnpm update:model-sizes
```

### 部署上线

```bash
# 构建静态网站
pnpm build

# 推送到GitHub，自动部署到GitHub Pages
git push
```

就是这么简单。
