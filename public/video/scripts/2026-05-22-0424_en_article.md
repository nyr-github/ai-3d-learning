# From AI Generation to Online Showcase: A Complete 3D Model Display Solution

## Introduction

Have you noticed recently?

There are so many projects popping up online that use AI to turn images into 3D models.

It sounds incredible - take an ordinary photo, feed it to AI, and out comes a beautiful 3D model. But I discovered a problem: many people work hard to generate 3D models with AI, only to let them sit idle on their hard drives.

Why? Because putting these models online for others to view and interact with isn't easy. You need to understand WebGL, Three.js, frontend development... For many people, that's a huge barrier.

That's exactly why I decided to do something different.

## Why I Built This Tool

I didn't do it alone. This time, I chose a complete Chinese AI toolchain - from model generation to website development, using domestic tools throughout:

**Step 1: Generate Images with Doubao**
Doubao's image generation capabilities are incredibly powerful. I input detailed prompts and generated beautiful scientific illustrations of plant cells, animal cells, mitochondria, and more.

**Step 2: Convert to 3D with Hunyuan 3D**
Tencent's Hunyuan 3D can transform a single image into a 3D GLB model. While some post-processing is needed, it dramatically lowers the barrier to 3D modeling.

**Step 3: Build the Website with Qoder**
This was the crucial step. Qoder, as an AI coding assistant, helped me rapidly build the entire 3D showcase website. From architecture design to code implementation, from performance optimization to responsive layout, the whole process was efficient and smooth.

I wanted to prove: with Chinese AI tools, anyone can turn their creativity into a shareable online experience.

## How It Works

### Complete AI Workflow

The entire process is simple:

1. **Prepare Images**: Use Doubao or other AI tools to generate high-quality images
2. **Generate 3D Models**: Use Hunyuan 3D to convert images to GLB format
3. **Optimize Models**: Use built-in scripts to compress model size (reduce by 50-80%)
4. **Add to Website**: Just configure a JSON file, no coding needed
5. **Deploy Online**: Push to GitHub Pages with one click, accessible globally

### Interactive 3D Display

Open the website, and you'll see a fully interactive 3D scene:

- **Free Rotation**: Mouse drag or finger swipe, observe the model from 360 degrees
- **Zoom View**: From whole to details, zoom in to see internal structures
- **Pan Movement**: Move interesting parts to the center of view

This isn't a simple image carousel - it's a true 3D experience.

### Rich Metadata Support

Each model isn't just "good-looking" - it can also include:

- **Detailed Descriptions**: Background stories, scientific explanations
- **Fun Facts**: Interesting facts that attract users
- **Teaching Focus**: Knowledge points for educational scenarios
- **Attribute Annotations**: Size ranges, microscope visibility, location info
- **Exam Points**: High-frequency test points specially marked

All this metadata can be added through simple JSON configuration, no code modification required.

### Out-of-the-Box Architecture

The project uses Next.js + Three.js + React Three Fiber tech stack:

- **Static Website**: Zero server cost, just deploy to GitHub Pages
- **Smart Caching**: Models are cached in memory after loading, instant switching
- **DRACO Compression**: Supports highly compressed GLB format, loading speed improved several times
- **Responsive Design**: Perfect adaptation for desktop and mobile

Most importantly, the code is completely open source. You can:

- Use it directly to showcase your own 3D models
- Modify configuration to customize your brand style
- Extend features to add what you need
- Learn from it to understand 3D web development best practices

## Technical Highlights

### AI Toolchain Integration

What makes this project unique is the complete domestic AI workflow:

**Doubao (Image Generation)**
- Supports detailed prompt control
- Generates high-quality scientific illustrations
- Can specify angles, styles, details

**Hunyuan 3D (Image to 3D)**
- Generates 3D models from a single image
- Outputs standard GLB format
- Supports textures and materials

**Qoder (AI Coding Assistant)**
- Understands project architecture, implements features quickly
- High code quality, follows best practices
- Assists throughout from requirements to deployment

### Intelligent Model Loading System

Not just "download-and-display", but uses advanced strategies:

1. **Memory Cache**: Loaded models are saved in memory, instant switching
2. **Preloading**: Predicts the next model users might view, loads in advance
3. **State-Driven**: Clearly tracks each phase (idle → downloading → parsing → completed)
4. **Error Handling**: Gracefully handles network issues and format errors

### Performance Optimization

- **Adaptive DPR**: Supports retina displays, balances clarity and performance
- **WebP Images**: Preview images use WebP, 30-50% smaller than PNG/JPG
- **DRACO Compression**: Model files reduced by 50-80%
- **Environment Maps**: HDR studio lighting, presents realistic materials

Just add new data configurations to extend new content, no code modification needed.

## Getting Started

### Quick Deployment

```bash
# Clone the repository
git clone <repository-url>
cd ai-3d-learning

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Visit `http://localhost:3000` to see it in action.

### Add Your Own Models

1. **Prepare GLB files**, place them in `public/models/` directory
2. **Prepare preview images** (WebP format), place them in `public/images/` directory
3. **Add configuration**, create or modify data files under `data/projects/`:

```typescript
{
  id: "my-model",
  name: "My Model",
  description: "Model description...",
  model3D: {
    modelUrl: "/models/my-model.glb",
    imageUrl: "/images/my-model.webp",
    displayScale: 1.0,
  }
}
```

4. **Run it**, see the effect immediately!

### Optimize Your Models

```bash
# Compress GLB files (reduce size by 50-80%)
pnpm optimize:glb ./public/models

# Convert images to WebP
pnpm convert:webp ./public/images

# Sync file sizes to configuration files
pnpm update:model-sizes
```

### Deploy Online

```bash
# Build static website
pnpm build

# Push to GitHub, auto-deploy to GitHub Pages
git push
```

It's that simple.
