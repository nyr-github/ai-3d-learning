# AI 3D模型开源展示平台：从生成到部署的完整解决方案

## 引言

最近AI生成3D模型特别火爆。

Tripo3D、混元3D、Rodin等工具让普通人也能轻松创建高质量的3D模型。输入文字描述或上传图片,几分钟就能生成一个立体的3D作品。

但你有没有发现一个问题？**生成的模型只能在那些平台里查看,无法展示在自己的网站上。**

作为一个热爱3D技术的开发者,我想要一个解决方案:能够快速搭建专属的3D展示空间,无论是展示AI生成的作品,还是自己的3D创作。

于是我开源了这个3D展示平台。

## 为什么我创建了这个工具

想法源于一个实际痛点:**AI 3D生成工具爆发式增长,但展示和分享仍然是难题。**

Tripo3D生成的精美模型、混元3D创建的角色、各种AI工具产出的作品,都被困在各自的平台里。你可能会想,网上不是有一些3D展示网站吗?

但仔细观察会发现两个问题:

**1. 很多演示站不开源**

- 你无法自己部署到自己的服务器
- 无法定制功能和界面
- 完全依赖别人的服务

**2. 只能展示特定类型的模型**

- 有的只能展示建筑模型
- 有的只能展示产品模型
- 想添加其他品类?改不动代码
- 核心逻辑和数据结构耦合太紧

于是我想要创建一个**真正通用的开源解决方案**,核心设计理念是:

**数据驱动,而非代码硬编码**

我设计了一个灵活的Entity3D数据结构,可以扩展任何类型的3D模型:

```typescript
interface Entity3D {
  id: string; // 唯一标识
  name: string; // 显示名称
  mainCategory: string; // 主分类
  subCategory: string; // 子分类
  description: string; // 详细描述
  funFact: string; // 趣味知识
  teachingFocus: string; // 教学重点
  attributes: Attribute[]; // 灵活的KV属性
  features: Feature[]; // 关键特征
  model3D: Model3DMetadata; // 3D模型配置
}
```

这个设计的优势:

- **添加新模型只需定义数据,不需要修改核心代码**
- **支持任意学科、任意品类** - 生物、化学、物理、建筑、产品...
- **灵活的属性系统** - 每个模型可以有自己的专属属性
- **统一的渲染引擎** - 无论什么类型,都能完美展示
- **自动适应展示方式** - 根据数据类型自动调整UI和交互

## 快速部署指南

部署你自己的3D展示平台非常简单,只需4步:

### Step 1: 克隆项目

```bash
git clone <repository-url>
cd ai-3d-learning
```

### Step 2: 安装依赖

```bash
pnpm install
```

### Step 3: 添加你的模型

将GLB文件放入 `public/models/` 目录:

```bash
cp your-model.glb public/models/
```

在 `data/projects/` 下创建模型配置,或在现有项目中添加:

```typescript
{
  id: "my-ai-model",
  name: "My AI Generated Model",
  model3D: {
    modelUrl: "/models/your-model.glb",
    imageUrl: "/images/preview.webp",
    displayScale: 1.0,
  }
}
```

### Step 4: 启动服务

```bash
# 开发模式
pnpm dev

# 或构建静态站点
pnpm build
```

访问 `http://localhost:3000` 即可看到你的3D模型!

### 部署到线上

平台支持静态站点部署,零服务器成本:

**GitHub Pages:**

```bash
pnpm build
# 推送到 GitHub,自动部署
```

**Vercel:**

```bash
vercel --prod
```

**Netlify:**
直接拖拽 `out/` 文件夹到 Netlify 控制台

## 平台技术亮点

作为一个开源项目,平台采用了现代化的Web技术栈:

### 核心交互功能

每个模型都支持:

- **360度旋转**: 拖动鼠标从任意角度观察
- **缩放控制**: 滚轮放大细节或查看全貌
- **平移导航**: 自由移动视角
- **光照调整**: 改变照明揭示不同特征
- **环境预设**: 工作室、城市或自然光照

### 性能优化

技术不应该成为障碍。平台采用多项优化:

**智能缓存系统:**

- 模型加载后自动缓存,切换时秒开
- 预加载你可能查看的下一个模型
- 内存监控,动态调整缓存策略

**DRACO压缩技术:**

- 模型文件压缩50-80%
- 保持视觉质量的同时加快加载
- 即使是复杂模型也能流畅运行

**响应式设计:**

- 桌面端: 三栏可调节布局
- 移动端: 触摸优化,滑出式侧边栏
- 自适应分辨率,视网膜屏幕完美显示

### 技术栈

- **Next.js 16**: 静态站点生成,零服务器部署
- **React 19**: 组件化架构,状态管理清晰
- **Three.js + React Three Fiber**: 3D渲染的完美结合
- **DRACO解码器**: Google开发的3D压缩标准
