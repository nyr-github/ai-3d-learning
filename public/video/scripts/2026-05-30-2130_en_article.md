# Open-Source 3D Model Display Platform: From AI Generation to Deployment

## Introduction

AI-generated 3D models are exploding right now.

Tools like Tripo3D, Hunyuan 3D, and Rodin let anyone create high-quality 3D models effortlessly. Just type a text description or upload an image, and within minutes you have a stunning 3D creation.

But have you noticed a problem? **Generated models can only be viewed inside those platforms—you can't showcase them on your own website.**

As a developer passionate about 3D technology, I wanted a solution: a way to quickly build a dedicated 3D showcase space, whether for displaying AI-generated works or my own 3D creations.

So I open-sourced this 3D display platform.

## Why I Built This Platform

The idea came from a real pain point: **AI 3D generation tools are growing exponentially, but display and sharing remain difficult.**

Beautiful models from Tripo3D, characters from Hunyuan 3D, creations from various AI tools—they're all trapped in their respective platforms. You might think, aren't there some 3D showcase websites online?

But if you look closely, you'll find two problems:

**1. Many demo sites are not open-source**

- You can't deploy them to your own server
- Can't customize features and interface
- Completely dependent on others' services

**2. Only work with specific model types**

- Some only display architectural models
- Some only show product models
- Want to add different categories? Can't modify the code
- Core logic and data structure are too tightly coupled

So I wanted to create a **truly universal open-source solution** with a core design philosophy:

**Data-driven, not code hard-coded**

I designed a flexible Entity3D data structure that can extend to any type of 3D model:

```typescript
interface Entity3D {
  id: string; // Unique identifier
  name: string; // Display name
  mainCategory: string; // Primary classification
  subCategory: string; // Secondary classification
  description: string; // Detailed description
  funFact: string; // Engaging trivia
  teachingFocus: string; // Educational objectives
  attributes: Attribute[]; // Flexible key-value attributes
  features: Feature[]; // Key structures/test points
  model3D: Model3DMetadata; // 3D model configuration
}
```

The advantages of this design:

- **Add new models by just defining data, no need to modify core code**
- **Support any discipline, any category** - biology, chemistry, physics, architecture, products...
- **Flexible attribute system** - Each model can have its own custom attributes
- **Unified rendering engine** - Whatever the type, it renders perfectly
- **Auto-adapts display modes** - Automatically adjusts UI and interactions based on data type

## Quick Deployment Guide

Deploying your own 3D display platform is incredibly simple—just 4 steps:

### Step 1: Clone the Project

```bash
git clone <repository-url>
cd ai-3d-learning
```

### Step 2: Install Dependencies

```bash
pnpm install
```

### Step 3: Add Your Models

Place GLB files in the `public/models/` directory:

```bash
cp your-model.glb public/models/
```

Create model configuration under `data/projects/`, or add to existing projects:

```typescript
{
  id: "my-ai-model",
  name: "My AI Generated Model",
  model3D: {
    modelUrl: "/models/your-model.glb",
    imageUrl: "/images/preview.webp",
    displayScale: 1.0,
  }
}
```

### Step 4: Start the Service

```bash
# Development mode
pnpm dev

# Or build static site
pnpm build
```

Visit `http://localhost:3000` to see your 3D models!

### Deploy Online

The platform supports static site deployment with zero server costs:

**GitHub Pages:**

```bash
pnpm build
# Push to GitHub, auto-deploy
```

**Vercel:**

```bash
vercel --prod
```

**Netlify:**
Simply drag the `out/` folder to Netlify console

## Platform Technical Highlights

As an open-source project, the platform uses a modern web technology stack:

### Core Interactive Features

Every model supports:

- **360-degree rotation**: Drag to view from any angle
- **Zoom controls**: Scroll to examine details or see the full picture
- **Pan navigation**: Move around freely
- **Lighting adjustment**: Change illumination to reveal different features
- **Environment presets**: Studio, urban, or natural lighting

### Performance Optimization

Technology should never be a barrier. The platform implements multiple optimizations:

**Intelligent Caching:**

- Models auto-cache after loading for instant switching
- Preload predicts your next likely selection
- Memory monitoring dynamically adjusts cache strategy

**DRACO Compression:**

- 50-80% file size reduction
- Maintains visual quality while accelerating loading
- Even complex models run smoothly

**Responsive Design:**

- Desktop: Three-column resizable layout
- Mobile: Touch-optimized with slide-out panels
- Adaptive resolution for retina displays

### Technology Stack

- **Next.js 16**: Static site generation, zero-server deployment
- **React 19**: Component architecture with clear state management
- **Three.js + React Three Fiber**: Perfect 3D rendering integration
- **DRACO Decoder**: Google's 3D compression standard
